This admin panel stores your experience entries, project cards, every text on the page and your CV on Supabase, so the live portfolio can load them. Add your project URL and anon key to js/supabase-config.js to finish the setup.

  1. Create a free project on supabase.com.
  2. Open the SQL editor and run supabase/schema.sql.
  3. Copy the Project URL and the anon public key from Settings → API into js/supabase-config.js.
  4. Add yourself as a user in Authentication → Users, then reload this page and sign in.

The full walkthrough is in SETUP-ADMIN.md.
